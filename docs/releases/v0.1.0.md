# Halodeck 0.1.0

The first public release.

Halodeck is a menu-bar app that turns a narrow strip along each side of the trackpad into a slider
and each corner into a button. The rest of the trackpad works as before.

## What's in it

- **Sides.** Press near a side until the trackpad clicks, then slide, to change the volume, the
  brightness or the keyboard light, seek, skip tracks, switch tabs, or press two shortcuts of your
  own. Each side has its own action. If you'd rather slide without pressing, turn on **Swipe** for
  that side in Settings › Bindings.
- **Corners.** A click in a corner can mute the sound or the microphone, press a key combination,
  open an app or a link, run a Shortcut, lock the screen, or show Mission Control, the app's
  windows, the desktop or Apps. A double click can run a second action.
- **Steps.** One step every 4 mm, a sixteenth of the range. Hold Option for steps four times
  smaller, or Shift to jump by eighths.
- **Feedback.** A light haptic tap at every step, and a short sound if you want one. On a MacBook
  with a notch, the level shows in the notch; on other Macs, in a pill under the menu bar. While the
  sound or the microphone is off, a small sign stays next to the notch.

Click the menu-bar icon to switch Halodeck on or off; right-click it to open the panel.

## Updates

A copy installed from the ZIP checks GitHub for new versions and asks before installing one. You
can turn the check off, or check now, in Settings › About. A Homebrew copy leaves updates to
Homebrew: run `brew upgrade --cask halodeck`, or click **Update with Homebrew…** in Settings › About.

## Privacy

The update check of a ZIP install downloads the update feed from GitHub, so GitHub sees the usual
request data, including your IP address. Turn automatic checks off in Settings › About if you'd
rather check yourself. A Homebrew copy doesn't check for updates on its own.

## Install

Needs an Apple silicon Mac with macOS 14 or later.

```sh
brew install --cask disc/tap/halodeck
```

Or download `Halodeck-0.1.0.zip` from
[Releases](https://github.com/disc/halodeck/releases/latest), unzip it, move `Halodeck.app` to
`/Applications` and open it. The first time, allow it in System Settings › Privacy & Security ›
Accessibility.

The release is signed with Developer ID and notarized by Apple. `SHA256SUMS.txt` has the archive's
checksum.
